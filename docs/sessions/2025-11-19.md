## 🚀 Estrategia GitHub Flow (FASE 5 - INFRAESTRUCTURA)

### 📋 Descripción General

Implementar CI/CD automático con GitHub Actions para garantizar calidad de código y deploy sin fricciones.

**Flujo**:
```
Feature Branch
    ↓
Push → Lint, Tests, Build, Analysis, Security
    ↓
PR Review
    ↓
Merge a main
    ↓
Build Final + Deploy a Homelab
```

### 🔧 Configuración de GitHub Actions

Todos los workflows se crean en `.github/workflows/`:

#### 1. **lint.yml** - PHP Pint + ESLint
- Ejecuta en: Push + PR
- Falla si hay errores de formato
- Verifica: PHP (pint) + JavaScript (eslint)

#### 2. **tests.yml** - PHPUnit + Vitest
- Ejecuta en: Push + PR
- Corre tests del backend + frontend
- MySQL service para tests
- Sube cobertura a Codecov

#### 3. **build.yml** - Vite React build
- Ejecuta en: Push + PR
- Compila assets para producción
- Valida que no haya errores de compilación
- Sube artifacts

#### 4. **analysis.yml** - PHPStan
- Ejecuta en: Push + PR
- Análisis estático de PHP
- Detecta bugs potenciales

#### 5. **security.yml** - Dependabot
- Ejecuta en: Diario + Push
- Verifica vulnerabilidades en dependencias
- composer audit + npm audit

#### 6. **deploy.yml** - Deploy a Homelab
- Ejecuta en: Push a main SOLAMENTE (merge de PR)
- Build final
- SSH deploy a homelab
- Comandos post-deploy: migraciones, cache clear, restart

### 🔐 Secrets a Configurar en GitHub

```
Settings → Secrets and variables → Actions:

HOMELAB_SSH_KEY    → Clave SSH privada (.pem)
HOMELAB_HOST       → IP/dominio (ej: 192.168.1.100)
HOMELAB_USER       → Usuario SSH (ej: deploy)
HOMELAB_PATH       → Ruta del proyecto (ej: /home/deploy/controlapp)
SLACK_WEBHOOK_URL  → (Opcional) Para notificaciones
```
