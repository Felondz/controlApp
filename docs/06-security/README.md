# 🔒 06-Security Documentation

Documentación sobre configuración de seguridad, escaneo de vulnerabilidades y buenas prácticas de seguridad en ControlApp.

## 📁 Contenidos

- **SECURITY_CONFIGURATION.md** - Guía completa de herramientas de seguridad configuradas
- **SECURITY.md** (en `.github/`) - Política de seguridad y cómo reportar vulnerabilidades

## 🎯 Propósito

Documentación sobre:
- Herramientas de seguridad configuradas
- Cómo monitorear vulnerabilidades
- Mejores prácticas de seguridad
- Respuesta a incidentes de seguridad

## 🛡️ Herramientas de Seguridad

| Herramienta | Tipo | Actualización |
|-----------|------|--------------|
| **CodeQL** | Static Analysis | Push, PR, Semanal |
| **Dependabot** | Dependency Scanning | Semanal |
| **Secret Scanning** | Secret Detection | Cada push |
| **PHPStan** | Type Analysis | Manual |
| **PHPCS** | Code Style | Manual |
